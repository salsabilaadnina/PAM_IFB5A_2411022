## Deskripsi

Aplikasi Manajemen Tugas Mahasiswa merupakan aplikasi mobile yang dirancang untuk membantu mahasiswa dalam mencatat, mengelola, dan memantau tugas perkuliahan.

Aplikasi ini nantinya dapat digunakan untuk mencatat daftar tugas, menentukan deadline, melihat status pengerjaan tugas, serta membantu mahasiswa mengorganisir tugas berdasarkan mata kuliah.

Aplikasi ini dikembangkan sebagai proyek pada mata kuliah Pemrograman Aplikasi Bergerak.
